### What’s New, Changed, and Fixed in DEX 3 RE Version 3.17

* M1 Macs native/full support
* New controller: Numark MixTrack Platinum FX
* New controller: Numark MixTrack Pro FX
* Added Audio Limiter (limits distorsions for higher audio levels)
* New setting in Audio Routing: Enable Limiter (disabled by default)
* Warn DJ when there is no current audio device set or is disconnected: “The audio device could not be found. Please re-connect it and restart the app or select a different audio device from Preferences/Options -> Audio Routing tab.”
* Fixed bend +/- buttons Learn mode (keyboard shortcuts) not working
* Fixed crash when updating singers list
* Fixed Windows audio device name with special characters
* Fixed activation/unlocking bug – would not activate in rare occasions
* Multiple crash fixes and performance improvements
